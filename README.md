# روض واحتي الصغيرة — نفس تصميم PDF

هذه النسخة تحافظ على التصميم البصري الأصلي للـPDF كما هو، وتعرض كل صفحة كصفحة مستقلة داخل موقع HTML.

## الملفات
- index.html
- style.css
- script.js
- pages/page-1.png ... page-9.png

## التشغيل
افتح `index.html` في Chrome أو Safari.

## ملاحظة
هذه الطريقة تحافظ على الشكل الأصلي بدقة عالية، لكنها تجعل محتوى الصفحة صورة/معاينة وليست عناصر HTML قابلة للتحرير. لتحويل كل عنصر (نص، صورة، زر...) إلى HTML/CSS قابل للتعديل مع الحفاظ على التصميم، يلزم إعادة بناء العناصر بصرياً صفحةً صفحة.
