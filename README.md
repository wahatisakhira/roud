# روض واحتي الصغيرة — نسخة HTML/CSS/JS

هذا المشروع يحول محتوى التصميم المرفق إلى موقع ويب مستقل من أربعة ملفات:

- `index.html` — هيكل الصفحات والمحتوى.
- `style.css` — التصميم المتجاوب والألوان والتخطيط.
- `script.js` — القائمة المتجاوبة والتفاعل مع النماذج.
- `README.md` — طريقة التشغيل.

## التشغيل
افتح `index.html` مباشرة في Chrome أو Safari.
